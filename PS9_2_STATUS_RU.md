# PYTHIA PS9.2 — packed context keys

## Изменение

В `src/entropy/cme68.rs` оптимизирован этап обучения разреженной контекстной модели PS9.0/9.1. Вместо создания временного `Vec<u8>` для каждого сочетания позиции и порядка контекста используется компактный `u64`: старшие 32 бита хранят длину (0..4), младшие 32 — байты контекста. Обратное преобразование в `Vec<u8>` выполняется один раз на уникальный контекст после подсчёта.

`BTreeMap` сохранён, поэтому порядок обхода и сериализация детерминированы. PYAE v6, нормализация частот, pruning, выбор контекста и декодер не изменены.

## Проверка

- Независимый Python differential-check на первых 524 288 байтах `mixed_10mb_compression_test.bin`.
- 4 902 уникальных контекста; все массивы частот из 256 элементов совпали со старым способом подсчёта.
- Проверена однозначность packed key и сортировка по длине, затем по байтам.
- Добавлены два Rust unit-теста для round-trip ключей и порядка.
- Старый цикл создавал 2 621 430 временных ключей-кандидатов на этом фрагменте. Новый цикл не выделяет heap-память для ключа на каждую позицию/порядок; `Vec` создаётся только один раз на уникальный контекст после агрегации.

## Ограничения

Проверена эквивалентность подсчётов, а не скорость. Время выполнения, пиковый RSS и полный размер архива PS9.2 не измерялись. `rustc`, `cargo` и `rustfmt` отсутствуют, поэтому Rust-компиляция и `cargo test` не подтверждены.

PS9.1 сохранена отдельно. Изменения PS9.2 затрагивают только encoder-side построение модели и не меняют формат кадра или декодер.
