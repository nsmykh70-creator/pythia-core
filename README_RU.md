# PYTHIA (pythia-core)

Экспериментальная lossless-система сжатия на Rust без внешних зависимостей: обратимые преобразования блоков, алгебраическая рекуррентная модель над кольцом `Z/256Z`, контекстное энтропийное кодирование с разреженными таблицами (PYAE v6), LZ77 v2, многофайловый контейнер с индексом и выборочным доступом.

Текущая версия: **PS9.8** (crate 0.9.8).

## Сборка и тесты

```bash
cargo build --release
cargo test
```

Состояние тестов PS9.8 (проверено нативной сборкой): 121 тест, 119 проходят; 2 известных падения описаны в `PS9_8_STATUS_RU.md` (stale-тест версии контейнера и тест расширения PS8.2, исправления подготовлены в отчётах соответствующих выпусков).

## Структура

- `src/container/` — контейнер PYAE v6: writer/reader, многофайловый контейнер с индексом (`multi.rs`), конвейер выбора представления блока (`pipeline.rs`), единый декодер дескрипторов (`format.rs`);
- `src/entropy/` — контекстный кодер v6 (`cme68.rs`), rANS, токенные дорожки;
- `src/transforms.rs` — модели-преобразования, включая `LaneTranspose` (ID 12), алгебраическую рекуррентную модель (ID 11) с побитовым подъёмом коэффициентов и `detect_record_stride`;
- `src/algebraic_search.rs` — исследовательский модуль нелинейного алгебраического предсказания (не интегрирован в production-селектор);
- `tests.rs` — интеграционные тесты;
- `benchmarks/` — независимые Python-эталоны и reference-реализации.

## История выпусков

Каждый выпуск сопровождается статус-файлом с полным списком изменений, независимыми проверками (Python-эталоны, контрольные суммы) и перечнем ограничений и непроверенного: `PS8_0_STATUS_RU.md` … `PS9_8_STATUS_RU.md`. Последние выпуски:

- **PS9.8** — LaneTranspose (ID 12), детектор шага записей, точный подбор рекуррентности подъёмом по битам; 39,98% на контрольном файле; формат не менялся;
- **PS9.7** — исправление критического бага читателей (единая функция `decode_block_descriptor` вместо трёх вызовов с лимитом параметров 0 — алгебраическая модель была записываемой, но нечитаемой) и защита писателя от превышения границы потока LZ77;
- **PS9.4–9.6** — исследовательские модули отбора трансформаций (standalone, без изменения production).
