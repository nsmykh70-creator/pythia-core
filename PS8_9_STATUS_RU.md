# PYTHIA PS8.9 — отчёт о разработке

## Состав версии

База: PS8.8. Предыдущие исходники не изменялись. Версия crate: `0.8.9`.

Добавлены две экспериментальные обратимые модели:

- `MODEL_WEIGHTED_MEDOID = 9` (`WeightedMedoid`): ансамбль из пяти детерминированных прогнозов. Для эксперта k с накопленной круговой ошибкой `L_k` вычисляется целочисленный вес `w_k = 1 + floor(2^20/(L_k+1))`. Выбирается прогноз-кандидат `p_j`, минимизирующий `sum_k w_k * d8(p_j,p_k)`, где `d8(a,b)=min((a-b) mod 256,(b-a) mod 256)`. После наблюдения байта обновляются накопленные ошибки всех экспертов.
- `MODEL_PROBABILISTIC_MIXTURE = 10` (`ProbabilisticMixture`): дискретная смесь пяти экспертных ядер. Для эксперта k и байта y используется целочисленная оценка `q_k(y)=max(1,floor(2^16/(1+d8(y,p_k))))`. Прогноз — кандидат среди пяти экспертных значений, максимизирующий `sum_k weight_k*q_k(y)`. После восстановления фактического байта веса обновляются пропорционально `weight_k*q_k(x)` и нормируются до `2^24`.

Обе модели используют те же пять базовых предсказателей PS8.8: ноль, предыдущий байт, линейная экстраполяция, квадратичная экстраполяция и XOR двух предыдущих байтов. Арифметика, веса и разрешение равенств детерминированы. Дополнительные данные в поток не записываются: декодер повторяет обновления по восстановленным байтам.

Обе модели добавлены в список кандидатов блочного поиска. Итоговый выбор контейнера по-прежнему сравнивает фактическую длину энтропийного кадра и дескриптора на полном блоке; новая модель не принуждается к использованию.

## Независимые проверки

Скрипт `benchmarks/ps8_9_ensemble_reference.py` — независимая Python-реализация алгоритмов для проверки синхронизации кодирования/декодирования. `benchmarks/PS8_9_REFERENCE_RESULTS.csv` содержит результаты диагностического zlib level 6 на синтетических потоках по 64 KiB.

| Набор | Identity | Weighted Medoid | Probabilistic Mixture |
|---|---:|---:|---:|
| Линейный | 585 B | 86 B | 86 B |
| Квадратичный | 582 B | 93 B | 90 B |
| Периодический текст | 256 B | 456 B | 268 B |
| Константный | 85 B | 86 B | 86 B |
| Случайный | 65 562 B | 65 562 B | 65 562 B |

Для обоих вариантов Python reference проверил побайтное восстановление каждого набора; SHA-256 восстановленного содержимого совпал с исходным. Скрипт скомпилирован через `py_compile`.

Время Python-эталона на 64 KiB составило около 0.7–0.8 с для Weighted Medoid и 1.0–1.4 с для Probabilistic Mixture на использованной среде. Это не оценка производительности Rust; показывает, что эталонный Python-код намеренно не оптимизирован.

## Интерпретация

Результаты не подтверждают универсального выигрыша. Модели очень хорошо помогают на выбранных линейных/квадратичных последовательностях, но Weighted Medoid ухудшает периодический текст; случайные данные остаются несжимаемыми. Поэтому модели оставлены экспериментальными кандидатами, а не обязательными стадиями. Финальный селектор должен сравнивать их с identity, LZ77 и другими цепочками по реальному размеру.

## Что не проверено

В среде отсутствуют `rustc`, `cargo` и `rustfmt`. Поэтому Rust-компиляция, `cargo test`, интеграционные тесты контейнера и замеры нативной скорости/RAM не выполнены. Python reference подтверждает математику и синхронность независимой реализации, но не заменяет сборку Rust.
