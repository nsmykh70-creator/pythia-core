# PYTHIA PS9.3 — алгебраическая рекуррентная модель

## Цель этапа

Главный приоритет проекта зафиксирован как максимальное lossless-сжатие. Ограничения по CPU и RAM вторичны. PS9.3 добавляет новый класс обратимого алгебраического преобразования, а не только оптимизирует существующие таблицы контекстов.

## Математическая модель

Байты рассматриваются как элементы кольца `Z/256Z`. Для каждого байта строится причинное предсказание четвёртого порядка:

`e[i] = x[i] - a1*x[i-1] - a2*x[i-2] - a3*x[i-3] - a4*x[i-4] (mod 256)`.

Начальная история считается нулевой. Преобразование обратимо для любых коэффициентов и любых входных байтов:

`x[i] = e[i] + a1*x[i-1] + ... + a4*x[i-4] (mod 256)`.

Коэффициенты подбираются на префиксе до 4096 байт детерминированным координатным поиском. Целевая функция — максимизация `sum_s count(s)^2`, то есть концентрации гистограммы остатков (эквивалентно минимизации энтропии Реньи порядка 2 с точностью до монотонного преобразования). Выполняются два прохода по четырём коэффициентам и всем 256 значениям каждого коэффициента. Итоговый выбор не опирается только на эту метрику: селектор кодирует кандидата и сравнивает точную сумму длины дескриптора и полного энтропийного кадра.

## Изменения

- Добавлен `AlgebraicRecurrence`, model ID 11.
- Параметры — ровно четыре коэффициента, записываемые в дескрипторе цепочки.
- Добавлен `fit_algebraic_recurrence`.
- Кандидат включён в общий поиск представления блока; для полного кодирования число проверяемых лучших трансформаций увеличено с двух до четырёх.
- Формат контейнера и существующие ID моделей не менялись; старые декодеры/архивы не должны затрагиваться.
- Добавлены Rust unit-тесты round-trip и валидации параметров.

## Независимые Python reference проверки

Контрольный файл: `mixed_10mb_compression_test.bin`, 10,485,760 байт, SHA-256 `999b1f32561deea75670f50d3cc7927565f78186b70e6f08602ae242b88a3c2f`.

| Данные | Коэффициенты | zlib исходник | zlib остаток |
|---|---:|---:|---:|
| mixed 10 MiB | 0,0,0,0 | 5,249,847 B | 5,249,847 B |
| linear 64 KiB | 1,0,0,0 | 585 B | 87 B |
| quadratic 64 KiB | 7,64,64,120 | 582 B | 289 B |
| LCG 64 KiB | 1,0,0,0 | 2,847 B | 329 B |
| random 64 KiB | 46,0,0,0 | 65,562 B | 65,562 B |

Python reference проверил полное восстановление 10 MiB контрольного файла и совпадение SHA-256 исходных данных. На смешанном контрольном файле модель закономерно не дала выигрыша; поэтому селектор должен отказаться от неё при сравнении полной стоимости. На линейной, квадратичной и LCG-последовательностях преобразование дало сильное снижение размера zlib-остатка. Это диагностический эксперимент с zlib, а не замер размера PYTHIA-контейнера.

## Ограничения и статус

- Rust unit-тесты добавлены, но не запускались: в текущем окружении отсутствуют `rustc` и `cargo`.
- Python reference round-trip выполнен; это не заменяет `cargo test`.
- Не заявляется, что PS9.3 уже улучшает сжатие всех типов файлов.
- Координатный поиск — локальная оптимизация; для некоторых полиномов может попасть в локальный максимум. Следующий этап должен исследовать многозапусковый поиск, совместный подбор коэффициентов и более точные оценки реального энтропийного размера.
