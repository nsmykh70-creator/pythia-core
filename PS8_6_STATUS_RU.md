# PYTHIA PS8.6 — статус разработки

## Цель

Улучшить математический критерий выбора профиля LZ77: минимизировать не промежуточный размер токенного PYLZ-потока, а размер полного entropy frame, который реально попадёт в блок архива.

## Изменения

- Базовая версия: PS8.5 (0.8.5).
- Для профилей hash-chain 32/48/64 кодируется один и тот же префикс блока размером до 64 KiB.
- Каждый пробный PYLZ-кандидат оценивается через штатный `entropy::encode_best`; в стоимость входят обычный entropy backend, token-aware PYAE v5, выбранная раскладка и заголовки.
- Выбирается минимальный полный размер кадра; при равенстве сохраняется предпочтение меньшей глубины из-за меньшей вычислительной стоимости.
- Полный блок кодируется один раз после выбора профиля.
- Для блоков меньше 4 KiB сохраняется профиль 32.
- PYLZ v2, model ID 5, декодер, контейнер и wire format не меняются.
- Добавлен тест детерминированности выбора профиля.
- Версия пакета: 0.8.6.

## Математический критерий

Для каждого профиля `d` на выборке `S` строится токенный поток `T_d(S)`. Оценка:

`J(d | S) = |E(T_d(S))|`,

где `E` — штатный полный селектор энтропийного кадра PYTHIA, включая заголовки и token-aware представление. Выбирается

`d* = argmin_{d in {32,48,64}} J(d | S)`.

При равенстве выбирается меньший `d`. Это практическая sample-based оценка конечной цены, а не доказанный глобальный оптимум для всего блока.

## Проверки и ограничения

- Исходники изменены и проверены статически на уровне структуры вызовов.
- В текущей среде отсутствуют `rustc`, `cargo` и `rustfmt`; компиляция и `cargo test` не выполнены.
- C++ эталон PS8.5 не воспроизводит полный Rust entropy selector, поэтому численные результаты PS8.5 нельзя переносить на PS8.6 как результаты измерений.
- Не заявляется измеренный выигрыш в размере или скорости PS8.6 до запуска Rust-тестов и полного benchmark.
- Дополнительная цена выбора профиля — до трёх энтропийных кодирований префикса; она должна быть измерена на целевой системе.
- Для больших блоков возможна оптимизация: использовать несколько коротких разнесённых проб, если это подтвердится экспериментами; пока оставлен один фиксированный префикс ради воспроизводимости.

## Совместимость

Изменение касается только encoder-side выбора глубины поиска. Декодер и форматы PYLZ/PYAE не меняются; PS8.6 должна оставаться совместимой с существующими декодерами.
